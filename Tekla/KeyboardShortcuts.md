# Tekla Structures — Default Keyboard Shortcuts

**Summary**: Curated subset of Tekla Structures 2026 default keyboard shortcuts, grouped by task. Focus on shortcuts a beginner actually uses during the demo workflow (model navigation, selection, snapping, drawings). Full list is on the official doc page.

**Sources**: https://support.tekla.com/doc/tekla-structures/2026/gen_keyboard_shortcuts

**Last updated**: 2026-06-05

---

> Customize via File → Settings → Keyboard shortcuts (also `Ctrl+Shift+C`).

## Tips

- **Beginner essentials** — burn these into muscle memory first: `Alt+P` (select previous), `Ctrl+A` (select all), `F2/F3` (selection switches), `F4-F7` (snap switches), `Ctrl+G` (filters), `Ctrl+E` (advanced options), `Ctrl+Q` (Quick Launch).
- See [[BeginnerTips]] for context — many of these shortcuts unlock the tips listed there.
- Roll your own shortcuts via `Ctrl+Shift+C` for things you do constantly (e.g. *Create current connection*).
