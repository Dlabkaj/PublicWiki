# Sweet Home 3D — Keyboard Shortcuts & Mouse Actions

**Summary**: Complete keyboard shortcut and mouse action reference for Sweet Home 3D (Windows, Linux, macOS).

**Sources**: [Sweet Home 3D shortcuts blog post](https://www.sweethome3d.com/blog/2019/03/29/sweet_home_3d_shortcuts.html) (July 17, 2022)

**Last updated**: 2026-06-22

---

> Notes: *(unverified — all entries from official source)*
> - Home/End/PgUp/PgDn = `fn`+Arrow on some laptops
> - `+` may require Shift depending on keyboard layout
> - Mac right-click = `Ctrl`+Click
> - "Win/Linux" column applies to both; Mac = separate column

## FILE

| Action | Win / Linux | macOS |
|--------|-------------|-------|
| New home | `Ctrl N` | `Cmd N` |
| Open home | `Ctrl O` | `Cmd O` |
| Save | `Ctrl S` | `Cmd S` |
| Save as | `Ctrl Shift S` | `Cmd Shift S` |
| Save and compress | `Ctrl Alt S` | `Cmd Alt S` |
| Close | `Alt F4` | `Cmd W` |
| Page setup | `Ctrl Shift P` | `Cmd Shift P` |
| Print | `Ctrl P` | `Cmd P` |
| Preferences | `Ctrl M` | `Cmd ,` |

## FURNITURE

| Action | Win / Linux | macOS / Mouse |
|--------|-------------|---------------|
| Select piece (catalog/list) | `Arrows` | Click |
| Select contiguous pieces | `Shift Arrows` | `Shift`+Click last |
| Toggle piece selection | `Ctrl`+Click | `Cmd`+Click |
| Add selected to plan at (0,0) | `Ctrl Shift F` | `Cmd Shift F` |
| Add anywhere in plan | — | Drag from catalog |
| Sort list column | — | Click header once (asc), twice (desc) |
| Modify selected | `Ctrl E` | `Cmd E` / double-click |
| Group selected | `Ctrl Shift G` | `Cmd Shift G` |
| Ungroup | `Ctrl Shift U` | `Cmd Shift U` |
| Align side by side | `Ctrl Shift B` | `Cmd Shift B` |
| Reset elevation | `Ctrl Shift Y` | `Cmd Shift Y` |
| Import 3D model | `Ctrl Shift I` | `Cmd Shift I` |
| Import texture | `Ctrl Alt I` | `Cmd Alt I` |

Import also works by drag-and-drop of OBJ / 3DS / DAE / KMZ / ZIP onto catalog, furniture list, or plan. *(unverified)*

## PLAN — General Selection & Navigation

| Action | Win / Linux | macOS / Mouse |
|--------|-------------|---------------|
| Select mode | `Ctrl L` | `Cmd L` |
| Select item | — | Click |
| Toggle item selection | — | `Shift`+Click |
| Rectangle select | — | Press+Drag over no item |
| Select hidden items | — | Right-click → Select object |
| Move selected 1 px | `Arrows` | Arrow keys |
| Move selected 10 px | `Shift Arrows` | `Shift`+Arrows |
| Move along H/V axis | — | Drag + `Shift` (after first move) |
| Duplicate | `Ctrl`+Drag | `Alt`+Drag |
| Duplicate along axis | `Ctrl Shift`+Drag | `Alt Shift`+Drag |
| Toggle magnetism (while dragging) | `Alt` (Win) / `Shift Alt` (Linux) | `Cmd` |
| Pan mode | `Ctrl Alt P` | `Cmd Alt P` |
| Pan (pan mode) | — | Drag |
| Pan (any mode) | — | `Space`+Drag |
| Pan up/down | `PgUp` / `PgDn` | Mouse wheel / trackpad swipe |
| Pan left/right | `Ctrl PgUp/PgDn` | `Shift`+wheel |
| Zoom in (+ fit selection) | `Ctrl K` / `Ctrl +` | `Cmd +` |
| Zoom out | `Ctrl Shift K` / `Ctrl -` | `Cmd -` |
| Zoom centered on cursor | `Ctrl`+Wheel | `Cmd`+Wheel |
| Lock base plan | `Ctrl Alt L` | `Cmd Alt L` |
| Unlock base plan | `Ctrl Alt L` | `Cmd Alt L` |
