# Sweet Home 3D — Operating Manual Index

**Summary**: Practical operating manual for Sweet Home 3D v7.5 — controls, shortcuts, and workflows for designing a house floor plan.

**Sources**: [Sweet Home 3D User's Guide](https://www.sweethome3d.com/users-guide/) · MCP plugin research (see [[../Index]])

**Last updated**: 2026-06-22

---

Sweet Home 3D is a free interior design app for 2D floor plan + 3D preview. Current stable version **7.5**, released May 5, 2025. GPL open source. Available in 29 languages.

## Platform availability

| Platform | Notes |
|----------|-------|
| Windows / macOS / Linux | Full feature set |
| iOS / Android | Mobile version; some features missing |
| Online (WebGL) | No 3D model import, no photo/video render, no menu bar (use contextual menus); auto-saves to server |

Download: `https://www.sweethome3d.com/`

Project files saved as **`.sh3d`** format — confirmed by [Creating 3D Floor Plans guide](https://www.sweethome3d.com/blog/creating-3d-floor-plans-with-sweet-home-3d/) ("Save your project as a .sh3d file") and [nice photo rendering blog](https://www.sweethome3d.com/blog/nice-photo-rendering-sweet-home-3d/) ("SimpleLights.sh3d").

## Recommended workflow (per official guide)

1. Import scanned blueprint as background image
2. Draw walls on the blueprint
3. Edit wall thickness / colors / textures
4. Add doors and windows
5. Add furniture; adjust size and location
6. Draw rooms; set floor/ceiling colors
7. Add levels (if multi-storey)
8. Draw dimensions and texts; print
