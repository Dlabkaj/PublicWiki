# Sweet Home 3D — User Interface

**Sources**: [Sweet Home 3D User's Guide](https://www.sweethome3d.com/users-guide/) · [Beginner's Guide (official blog)](https://www.sweethome3d.com/blog/beginners-guide-to-sweet-home-3d-for-diy-home-designers/)

## Four panes

| # | Position | Pane | Purpose |
|---|----------|------|---------|
| 1 | Top-left | **Furniture catalog** | All furniture/objects organised by category; click triangle to expand category |
| 2 | Bottom-left | **Home furniture list** | Furniture in current home; sortable by clicking column headers |
| 3 | Top-right | **Home plan** | Top-down 2D floor plan with grid and rulers; draw walls, place furniture here |
| 4 | Bottom-right | **Home 3D view** | Real-time 3D preview; updated on every plan change |

Grid positions confirmed by [Beginner's Guide](https://www.sweethome3d.com/blog/beginners-guide-to-sweet-home-3d-for-diy-home-designers/) and [User's Guide](https://www.sweethome3d.com/users-guide/).

All panes are resizable. *(needs second source)*

## Focus

- Active pane shown by **colored border rectangle** — confirmed by [User's Guide](https://www.sweethome3d.com/users-guide/) ("colored rectangle that surrounds it") and [Shortcuts blog](https://www.sweethome3d.com/blog/2019/03/29/sweet_home_3d_shortcuts.html) ("pane surrounded by a colored rectangle receiving keyboard inputs").
- Transfer focus: **Tab** / **Shift+Tab**, or click the target pane.
- Some operations depend on which pane has focus — confirmed by [User's Guide](https://www.sweethome3d.com/users-guide/) and [Shortcuts blog](https://www.sweethome3d.com/blog/2019/03/29/sweet_home_3d_shortcuts.html).

## Undo / Redo

- **Undo** and **Redo** toolbar buttons — confirmed by [User's Guide](https://www.sweethome3d.com/users-guide/) ("clicking on the Undo and Redo buttons in the tool bar") and [Shortcuts blog](https://www.sweethome3d.com/blog/2019/03/29/sweet_home_3d_shortcuts.html) (Ctrl+Z / Ctrl+Y).
- All modifications in the home plan are undoable. *(needs second source)*

## Preferences dialog

| OS | Menu path |
|----|-----------|
| macOS | **Sweet Home 3D > Preferences…** |
| Windows / Linux | **File > Preferences…** |

Check here before starting: default unit, default wall thickness, default wall height. *(needs second source)*

## Toolbar key items (mentioned in guide)

- **New home** — create fresh project
- **Create walls** — enter wall-drawing mode
- **Create rooms** — enter room-drawing mode
- **Create dimensions** — enter dimension-drawing mode
- **Add texts** — enter text-placement mode
- **Add furniture** — add selected catalog piece to plan
- **Zoom in / Zoom out** — change plan scale
- **Undo / Redo**
- **Save home** — manual save (Online version auto-saves)
- **Create photo…** — open photo render pane
- **Create video…** — open video render pane

## Advanced: combining furniture

Multiple furniture pieces can be combined to create new composite objects. Confirmed by [Beginner's Guide](https://www.sweethome3d.com/blog/beginners-guide-to-sweet-home-3d-for-diy-home-designers/) and [Aaron Godfrey blog](https://aarongodfrey.dev/home%20automation/tips_for_creating_a_3d_floorplan_using_sweethome3d/) ("Get Creative" section).
